01 / CONTEXTO

El origen de Donit

DoNit fue mi Trabajo de Fin de Grado de DAM. Desarrollé una solución completa de gestión de tareas con clientes Android y JavaFX.

Ambos clientes consumían una API REST en Spring Boot, protegida con JWT y conectada a PostgreSQL. La desplegué en AWS y después seguí evolucionando la idea hasta Donit v1.0.0.

02 / CONTRIBUCIÓN

Mi papel

ROL PRINCIPAL / FULL-STACK DEVELOPER

Desarrollo principal · Arquitectura · Integración · Despliegue

Diseñé la aplicación y la arquitectura del sistema como una solución completa. Desarrollé el backend en Java y Spring Boot, la API REST y la persistencia con JPA/Hibernate y PostgreSQL.

Implementé la autenticación y seguridad con Spring Security, JWT y BCrypt. Desarrollé y di soporte a funcionalidades, integrando los clientes Android y JavaFX con el backend.

Clientes e integración Android y JavaFX conectados a la misma API REST: integración entre frontend y backend.
Despliegue completo AWS EC2, RDS, Elastic IP, Security Groups y systemd. Puesta en funcionamiento del sistema completo.

Diseñé e integré el sistema como una solución completa. Una API en Java y Spring Boot compartía la lógica entre ambos clientes; Spring Security y JWT protegían el acceso y JPA/Hibernate gestionaba la persistencia en PostgreSQL.

04 / ACCESO

Autenticación y seguridad

El registro y el login se integraban con Spring Security. Las contraseñas se almacenaban con BCrypt y JWT permitía acceder a endpoints protegidos.

Las tareas y sus tipos estaban relacionados con el usuario autenticado.

05 / INFRAESTRUCTURA ORIGINAL

Despliegue original en AWS

  1. Android / JavaFX
  2. Internet
  3. Elastic IP
  4. EC2 · Amazon Linux
  5. Spring Boot API
  6. Security Groups
  7. RDS PostgreSQL

Realicé el despliegue original mediante AWS Academy. La API se ejecutaba en una instancia EC2 con Amazon Linux y Elastic IP.

PostgreSQL estaba alojado en RDS. Los Security Groups limitaban la comunicación entre la instancia y la base de datos.

El backend se ejecutaba como servicio mediante systemd.
