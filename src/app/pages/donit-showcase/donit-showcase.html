01 / SISTEMA

Qué es Donit

La app principal es Android nativa, creada con Kotlin y Jetpack Compose. Permite gestionar tareas, planificar y consultar estadísticas.

El sistema incluye una API REST en Spring Boot, un Admin web en Angular y una demo pública sin login. Todo se ejecuta en infraestructura propia.

04 / SISTEMA

Arquitectura

Una API REST en Java 21 y Spring Boot conecta las tres superficies con PostgreSQL. Spring Security y JWT protegen las rutas privadas; Flyway gestiona la evolución de la base de datos.

  • Android→ Spring Boot API → PostgreSQL
  • Angular Admin→ Spring Boot API
  • Demo pública→ API pública
05 / OPERACIÓN

Infraestructura y despliegue

Donit se despliega en un servidor Linux propio, con servicios en Docker y PostgreSQL. Cloudflare Tunnel y dominios propios ofrecen acceso a los servicios.

Los entornos DEV y PROD están separados. GitHub Actions construye y publica artefactos en GHCR para el despliegue automatizado; Android, API y Admin tienen releases independientes.

06 / PROTECCIÓN

Seguridad

Spring Security y JWT gestionan el acceso, las sesiones y los permisos Admin. Las rutas públicas y privadas están separadas. El APK Android se firma de forma segura y los secretos permanecen fuera del repositorio.

07 / ENTREGA

Calidad y entrega

Tests automatizados, tests Android unitarios e instrumentados y lint Android forman parte de la validación. Flyway acompaña los cambios de datos; GitHub Actions ejecuta CI/CD y builds release. La entrega sigue versionado semántico, con v1.0.0 como hito.
